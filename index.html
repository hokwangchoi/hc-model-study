Learning path

Foundation-model architectures studied for GPU and edge inference: where the tensors go, what each operation costs, and which optimizations matter. Nine modules in order, plus two hands-on tutorials you build yourself.

9 modules, each with an interactive guide, a runnable .py and a README 2 hands-on tutorials: an LLM and an agent Runs on a CPU; torch>=2.0

Map

Arrows point from a prerequisite to the module that builds on it. Numbers give the recommended order; dashed boxes are the hands-on tutorials. Click a box to open its guide.

Mamba and MoE need only the Transformer, so you can take them earlier; the numbered order interleaves vision and language so each module reuses something recent.

Hands-on track

Two tutorials where you build the thing yourself, end to end, on a laptop. Take the first right after the Transformer module.

  1. T1

    Build an LLM from scratchtutorial

    Byte-level BPE, a GPT decoder (RMSNorm, RoPE, SwiGLU, tied embeddings), pretraining, sampling, a tested KV cache and SFT. Trains in about a minute on 4 CPU threads, no downloads.

    After: TransformerAdds: the full training and inference pipeline, written and run yourself
    Open guide →READMEpython build_llm.py all
  2. T2

    Build a personal agenttutorial

    A tool-use loop on the Claude Messages API with notes search, memory, guardrails and evals. A scripted mock model runs everything offline.

    After: Build an LLMAdds: agent loop, safe tools, BM25 retrieval, guardrails, evaluation, Agent SDK and MCP
    Open guide →READMEpython evals.py

How to study this repo

The same five steps for every module. The guides end with the material for steps 3 and 4.

  1. Read the guideFollow the tensor shapes through each diagram; use the calculators with your own model sizes.
  2. Run the .pypython <module>.py prints shapes, parameter counts and FLOPs. Change a dimension and predict the output first.
  3. Do the exercisesEach has a self-verification step, usually an assertion you can run.
  4. Take the self-checkAnswer before opening the hidden answers; redo the numeric ones on paper.
  5. Revisit after a few daysRetake the self-check cold. Whatever you missed, reread that section only.

Suggested study cadence

About two modules a week, at 4–6 hours per module including running the code and some exercises. Plan more time if you do every exercise, less if you only read.
