Hands-on lab 07 of 10 · Mamba selective scan

Mamba's selective scan: sequential, parallel and recurrent

Implement the core of a Mamba layer, the selective state-space scan, three ways that must agree:

  • a sequential loop over time (the definition),
  • a parallel prefix scan in O(log L) rounds (how training runs),
  • a one-token recurrent step with a fixed-size state (how generation runs). The projections around the scan (in_proj, conv, gating) are ordinary layers and are left out.
Time: 60-90 minCheck: python labs/check.py 7
Open in Colab ↗ Notebook (.ipynb) Lab file (.py) All labs

The maths, step by step

b batch, L sequence length, D channels, N state size per channel. Every channel d runs its own little linear system with an N-dim state.

Inputs   x [b, L, D]       the sequence (the paper's x_t; mamba.py calls it u)
         delta [b, L, D]   step size, > 0, per token and channel (input-dependent:
                           delta = softplus(Linear(x)) in Mamba)
         A [D, N]          learned, negative (decay rates)
         B [b, L, N]       input → state, per token (input-dependent)
         C [b, L, N]       state → output, per token (input-dependent)
         D_skip [D]        direct skip connection (optional)
  1. 1
    Discretize (continuous system → one update per token):
    A_bar[t, d, n] = exp(delta[t, d] * A[d, n])            in (0, 1): how much to keep
B_bar[t, d, n] = delta[t, d] * B[t, n]                  ("simple", what Mamba's kernel uses)
or, exact zero-order hold for diagonal A:
B_bar[t, d, n] = (exp(delta A) - 1) / A * B[t, n]       ("zoh"; equals the simple rule
                                                        to first order in delta)

    Large delta: forget the past, write the input. Small delta: keep the state.

  2. 2
    Recurrence (h_0 = 0, or a given h0):
    h_t = A_bar_t * h_{t-1} + B_bar_t * x_t               h: [b, D, N]
y_t = sum_n C_t[n] * h_t[:, :, n]  + D_skip * x_t      y: [b, D]
  3. 3
    Each step is an affine map h → a * h + c with a = A_bar_t, c = B_bar_t x_t.

    Doing step 1 then step 2 is again affine:

    (a2, c2) o (a1, c1) = (a2 * a1,  a2 * c1 + c2)

    This combine is associative, so all prefixes h_1..h_L can be computed in ceil(log2 L) rounds (Hillis-Steele): in round r, every position t combines with position t - 2^r. After the last round position t holds the composition of steps 1..t, whose c part is h_t (because h_0 = 0).

  4. 4

    Generation: carry only h [b, D, N] (constant size, no KV cache) and apply the recurrence once per new token.

Worked numbers (A = -1, B = 1): delta = 0.1 → A_bar = 0.905; delta = 5 → 0.0067.

Hint 2

3 the associative combine and the parallel scan

scan_combine(a1, c1, a2, c2)

to write

Compose two affine steps: first (a1, c1), then (a2, c2).

Applying the result to h must equal a2 * (a1 * h + c1) + c2. Returns (a, c), elementwise.

Hint 1
expand a2 * (a1 * h + c1) + c2 and read off the factor of h and the constant.

parallel_scan(a, c)

to write

All prefixes of h_t = a_t * h_{t-1} + c_t with h_0 = 0, in O(log L) rounds.

a, c: [b, L, ...] (time is dim 1). Returns h: [b, L, ...] with h[:, t] = h_{t+1} in 1-based maths, i.e. the state AFTER processing element t. Do not loop over L; loop over the rounds offset = 1, 2, 4, ... < L.

Hint 1
in each round every position t >= offset combines with position t - offset, which comes EARLIER in time: (a, c)[t] = (a, c)[t-offset] then (a, c)[t].
Hint 2
positions t < offset combine with the identity step (a = 1, c = 0); pad with a_prev = torch.cat([torch.ones_like(a[:, :offset]), a[:, :-offset]], dim=1) and the same with zeros for c.
Hint 3
a, c = scan_combine(a_prev, c_prev, a, c); offset *= 2. At the end return c.

selective_scan_parallel(x, delta, A, B, C, D_skip=None)

to write

Same y as selective_scan_sequential (h0 = 0), via discretize + parallel_scan.

Hint 1
the affine step of token t is a = A_bar_t, c = B_bar_t * x_t ([b, L, D, N]).
Hint 2
h = parallel_scan(A_bar, B_bar * x[..., None]); y = (h * C[:, :, None, :]).sum(-1)
